# Tide & Trail — Community + Gear + Environment

This version restores the original visual/emotional design and carries the business model forward.

### Core pages
- Home: emotional photography, community, marketplace, Footpath rentals, Hush Hush, consignment
- Shop: searchable marketplace + Fresh Drop Tuesday banner
- Sell: photo-first consignment intake + cash / Tide & Trail credit model
- Rent: Fundy Footpath 3–5 day rental kits
- Community: Hush Hush, events, Adventure Board
- Fresh Drop Tuesday: Monday processing → Tuesday live sale → online inventory
- Repair: repair-before-replace environmental layer
- About: brand story and visual imagery

### Assets
The full `public/assets` folder is included. Do not remove it. Images are referenced from `/assets/photography/` and logos from `/assets/logos/`.

### Deploy
Upload the contents of `tide-trail-site` to the GitHub repository root, then deploy to Vercel. Run `npm install` and `npm run build` locally if desired before pushing.
